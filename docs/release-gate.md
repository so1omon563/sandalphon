# Historical First Public Release Gate

> [!CAUTION]
> Sandalphon is a canceled feasibility project. This gate is permanently
> **no-ship** under ADR 0008. Do not create, package, install, publish, or
> distribute a Sandalphon release from this document.

The former gate tracked source checks, physical-device evidence, installation
lifecycle, security claims, documentation, licensing, artifact provenance, and
release approval. The project did not meet its central product requirement:
controlling the user's active visible Codex Desktop task through a supported
interface.

The official Codex app-server proof operated a separate Sandalphon-owned
session. The private Desktop mechanisms explored during feasibility work were
unsupported and sensitive to frequent Codex Desktop updates. Passing additional
package or hardware checks could not correct that missing control boundary.

No supported Sandalphon version, installer, package, GitHub Release, or ship
outcome exists. The detailed former gate remains available in repository
history solely as research evidence.

Product or release work may be reconsidered only after the reactivation
conditions in the root `AGENTS.md` are met and the project contract, Linear
project, and durable wiki status are updated first.

See [ADR 0008](architecture/decisions/0008-cancel-product-feasibility.md) for
the authoritative decision.
